## Programming

My current main interest is definitely Machine Learning and AI. The past year I have been delving into the internals of building coding agents, using LLMs at scale, context engineering, and MCP tool use. In my free time I have been exploring a bit more into model research, trying to implement papers from scratch to improve my skills in machine learning.

In terms of programming languages I cannot say I have a favorite. My most used language by far is python, but I have worked in so many that it is hard to keep track. I think my favorite part of programming is building quick prototypes to bring ideas to fruition. For me, the part of programming that brings joy, more than anything else, is the creation of value. The ability to take an idea and turn it into reality. In this sense, python is extremely strong, as it is built for speed of development. This is probably also why I really enjoy coding agents and vibe coding. Despite this I recognize the value of various languages such as Rust or Closure, which bring their own strengths in performance, or data pipeline modeling.

Recently I also moved my main Desktop to Linux and have been getting into Arch via [Omarchy](https://omarchy.org/).
